# ゆるもじ島の漢字探検隊

Codexへの引き継ぎ用ソース。2026-10-26作成。

## 起動

依存パッケージやビルドは不要。展開したフォルダで次を実行し、http://localhost:8000 を開く。

```sh
python3 -m http.server 8000
```

JavaScript構文確認:

```sh
node --check app.js
```

## ファイル

- index.html: エントリーポイント
- style.css: レスポンシブ画面
- app.js: 問題データ、マップ、クイズ、報酬、復習、図鑑
- assets/: 既存キャラクター5人と島のWebP画像
- CODEX_HANDOFF.md: 開発引き継ぎ
- AGENTS.md: 作業方針

## GitHubへ移す

新規リポジトリ、または既存リポジトリの専用ブランチへ、このフォルダ内のファイルを配置する。既存ファイルを無確認で上書きしない。そのリポジトリをCodexの作業対象にする。

## 保存について

進み具合はlocalStorageの `yurumoji-v1` に保存。サーバーや別端末とは同期しない。公開先のURLが変わると以前の保存データは自動では引き継がれない。

## 公開

任意の静的ホスティングでルートのindex.htmlを配信可能。このZIPには元のSitesの接続情報・Git履歴・認証情報を含めていない。公開済みサイトへの自動反映は設定されていない。
